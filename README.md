# AI免证 Web MVP

按用户提供的 [Figma 设计](https://www.figma.com/design/2tTCHpez2WMOkDUqswhS2N/Untitled?node-id=21-3397) 实现四个可操作界面：登录、首次声线录入、对话录音、提醒与结果。

这是验证视觉与交互的独立演示版。账号校验、声线计时、对话和应对结果均为本地演示；不会请求麦克风权限，不会录音、生成声纹或连接后端，也不会读取项目的 `.env`。

在原项目中提交 Web 修改后，可再次发布：

```powershell
cd 'D:\AI免证'
node scripts/publish-web-github.mjs
```

该脚本位于原项目，需要 GitHub CLI 已登录；通过 GitHub API 上传当前提交中的 `web/` 文件，不会上传未提交的修改，也不会强制覆盖远程分支。运行前先提交要发布的 Web 修改。它适用于本机 Git 推送连接不稳定的情况。

若直接克隆网页仓库修改，正常提交并推送其 `main` 即可。发布进度在仓库的 Actions 页面查看。

## 启动

需要 Node.js 20 或更新版本，无第三方运行依赖，无需 `npm install`。PowerShell 执行：

```powershell
cd 'D:\AI免证\web'
npm.cmd run dev
```

终端显示 `AI免证 Web MVP: http://localhost:5173` 后，用浏览器打开这个地址。保持终端运行；按 `Ctrl+C` 停止。若端口被占用，先停止之前的预览服务（关闭浏览器标签不会停止服务），或在当前终端使用 `$env:PORT='5174'` 再运行，打开新的端口。

## 亲自走一遍

1. 登录页：两个输入框为空时，“登录”不可点；填入演示账号和任意错误密码，应看到“账号密码不正确”；换成演示密码再登录。
2. 首次进入声线页：点击“开始录入声线”，计时应增加，并出现“完成声线录入”“取消本次录入”。取消后回到 `00:00`；不足 5 秒完成会提示重新录入。等约 10 秒再完成，会自动进入对话录音页。20 秒时演示会自动完成。
3. 对话页：看到“正在录音”、本人／对方两条演示对话。默认“录一段后分析”。点击“结束录音”，按钮短暂变成不可点的“正在收尾…”，随后进入提醒页。
4. 结果页：先看到“先稳住。”和“正在生成应对方案…”，约 1.4 秒后出现“可以这样说”、完整回复、意图推测和可选行为。点击“开始新一段”回到对话页，计时从零开始。
5. 在录音中选择“边听边生成”：应提示“下一段生效 · 本段仍为录一段后分析”。结束本段并在结果页点击“开始新一段”，新段才使用实时模式。约 8 秒后自动展示这一轮的演示结果，显示“录音仍在继续”；点击“返回对话”后计时继续，仍可结束录音。
6. 刷新页面后再次登录：如果之前完成过演示声线录入，应直接进入对话页。刷新会中止当前演示录音，不会恢复会话。

为了模拟“首次录入后沿用”，浏览器只保存 `aimianzheng.web-demo.voice-template.v1=ready` 这一完成标记；不保存密码、音频和声纹。需要重新体验首次录入时，使用浏览器隐私窗口打开预览，或在开发者工具的控制台执行：

```javascript
localStorage.removeItem('aimianzheng.web-demo.voice-template.v1');
location.reload();
```

## 文件用途

| 文件 | 用途 |
| --- | --- |
| `dist/index.html` | 预览外壳、手机状态栏与演示说明。 |
| `dist/styles.css` | Figma 的颜色、字号、间距、卡片和窄屏换行。 |
| `dist/app.js` | 四个页面的本地演示状态和按钮操作。 |
| `dist/assets/figma/` | 从该 Figma 文件下载的原始 SVG 图标，不依赖临时链接。 |
| `serve.mjs` | 只向本机提供 `dist/` 静态文件的预览服务。 |
| `package.json` | 启动和 JavaScript 语法检查命令。 |

`dist/` 在这个无构建工具的 MVP 中直接存放源码，不是自动生成目录。页面优先使用 Figma 的 Noto Sans SC 字体，本机已安装；其他设备缺少该字体时会回退到微软雅黑或系统字体，字形可能略有差异。390×844 为参考尺寸；较小窗口通过滚动查看底部内容。

## 后续改代码时注意

- `currentMode` 是本段的模式，`nextMode` 是下一段的模式，不能合并，否则录音中切换会立刻改变本段行为。
- 实时结果的“返回对话”只换页面，不能调用 `startSegment()`，否则计时会重置。
- `generationId` 用来挡住上一段延迟返回的结果；保留这个检查，避免新一段被旧结果覆盖。
- 当前演示数据集中在 `app.js`。接真实接口时需要替换完整数据路径；不能把当前的完成标记当作真实声纹模板，也不能把云服务密钥放进网页。

原有 Android App、FastAPI 后端及阿里云部署计划不受这个演示版影响。真实录音、登录、Paraformer、DeepSeek、耳机和侧边键不在本次 Web 视觉验证范围内。
